# Codex 自主执行规约

## 0. 不需要逐阶段向用户请求确认

本轮授权：在既有隔离工作树内**连续进行 E3、E4、E5、E6 的源码开发、非破坏性测试与候选构建**。每阶段通过就直接进行下一阶段；不要每做一个测试就停下来询问用户。Codex 的当前会话/运行环境权限、执行时间、资源限制仍有效；不可声称会无限期后台运行。不可自行发布远端内容。

## 1. 恢复工作上下文（先读，不修改）

1. `pwd; git branch --show-current; git rev-parse HEAD; git status --porcelain=v1; git worktree list --porcelain`。确认工作树和分支，不满足则阻止任何写操作；不能自动切换/重置/清理分支。
2. 阅读上级 002 规范、本补充规范、最近 `E3_REPORT.md`、`IMPLEMENTATION_REPORT.md`、`tests/m19ef/README.md`、阶段日志/Manifest。此前用户报告的数字先记录为 `reported`, 再用日志核对为 `verified`。
3. 枚举本地所有 staged/unstaged/untracked 文件，记录 Git 状态和源清单。**未提交的当前代码是宝贵的工作成果，不允许丢弃。** 禁止把 Git HEAD 当成完整的工作树源码。
4. 记录本地原生 Mio Seed 的可信 SHA256 和签名校验，禁止盲用旧 Go 组件、旧工作树构建输出或不匹配的二进制。
5. 建立阶段检查表，决定已有哪几项完成、哪些仍需自动接入、补测试、做受影响回归；不要重复历史局部已通过的无关实验。

## 2. 真实实施循环

对 E3→E4→E5→E6：

- 缩小到最小可重现失败样例→归属 GC core / RuntimeOp / CPU / OS / Compiler lowering→实现真实纯 Mio 代码→native 编译、签名、运行→负向/对抗测试→回归。
- 编译器自身生成程序、实际运行原生用户程序作为生产路径主证据，禁止 mock 替代生产执行。Mock 只能证明合同。
- 修改共享 GC ABI/编译器自动插桩后，重验所有可能受影响的旧门禁；不沿用旧源码构建出的镜像证明新源码完整通过。
- 完成每阶段后写报告、通过或阻塞依据、证据路径、可复现命令。**只有全部明确门禁通过才能进入下阶段的正式实现**；前置工作可预调查，但不得提前认定未来阶段 PASS。
- 重型测试串行，避免与 GF5/其他工作树的自举和压力测试抢资源，保存资源争用信息。

## 3. 非常重要的代码修改界限

**允许**在当前 worktree 修改 `bunko/**/*.mio`、`selfhost/**/*.mio`、`tests/m19ef/**/*.mio`、必要的测试驱动（不能进入生产依赖图）、本补充规范的报告、机器码后端适配器及兼容验证。

**不得**修改其他工作树、发布分支或历史验收源文件；历史记录只追加说明或新证据，不重写旧 PASS/FAIL。禁止删除或关闭失败测试来通过 Gate；对于无效旧黄金值，只能版本化迁移并同时保存原始证据。

**禁止** Git Commit/Push/Tag/Release、历史重写、reset --hard、clean、stash；不自动删除 `build/m19ef-evidence/` 下任何已有证据；每次运行使用全新证据目录。禁止未经必要性审计扩大语言语法/全局 API，禁止顺手开启 M19f。

## 4. 发生失败时

- **真实错误**：主动复现、定位修复、重跑受影响 Gate；失败日志保留，不得用预设成功码或跳过用例掩盖。
- **超时/死锁**：保存进程/CPU/线程快照、最后已验证阶段、deadline 和真实退出码；不要阻止/杀掉其他 worktree 的任务。自身被启动的进程可在安全清理后停止。
- **外部限制**：记录 BLOCKED 原因和下一条可执行命令；不要报告未来完成，也不要重复追问用户已给的路径与限制。
- **无法证明的并发安全**：保持目标后端 concurrent capability 为 false；旧 STW 可以安全使用，但不能标记 Concurrent PASS。

## 5. 自动恢复

中断后的下一会话首先检查源码 Manifest + 当前报告 + 实际 artifacts。若最近测试的 Manifest 与当前源码不一致，则该结果只能作历史证据；应继续从最近真实可复现检查点推进。

执行最后输出 `E3/E4/E5/E6` 各自状态、影响文件、真实成功/失败日志位置、最新源码 SHA256、最终自举情况及下一条可执行命令。禁止在尚未完成时使用「M19e PASS」「v2.1.0 ready」。
