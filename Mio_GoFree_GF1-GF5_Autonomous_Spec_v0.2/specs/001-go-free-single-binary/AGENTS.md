# AGENTS — Mio GF1～GF5 自主开发守则

你是受托完成 Mio Go-free 单文件原生工具链 GF1～GF5 的实现者。当前目录是规范根；请从项目根目录执行实际开发。

## 自动工作授权

- 用户明确要求你**连续完成 GF1～GF5**。不要在每个任务、每个阶段、每次普通源码修改前要求确认；在安全范围内自行作出可逆工程决策，修改、编译、测试、诊断并重试。
- **GF0 已完成**。不得以重复 GF0 代替 GF1 开发；先核查 GF0 来源和当前工作树差异，再从 GF1 开始。
- 每次通过一个阶段必须**继续下一个阶段**，不能仅报告阶段完成便停止，除非执行环境中断、必要资料不可得或安全红线阻止继续。
- 选择最小可维护实现；先小型端到端纵切，再扩展全量语义。遇到失败先定位根因与补充回归，再修复。
- 不允许只是撰写计划或临时 mock 后宣告通过。每个实现都必须在实际原生 Mach-O 上被运行和验证。

## 不可逾越的约束

- 原仓库和其他 worktree（`EXP/m19-race-gate`、`EXP/m19d-admission` 等）在本任务中只读；新建专用 worktree 后只能修改它。
- 不执行 `git reset --hard`、`git clean`、在原仓库 stash、覆写用户修改、删除历史 M18/M19/GF0 证据。
- 不自动 Push、重写远程历史、创建/推送 Tag、发布 Release、上传二进制或使用生产密钥。允许生成本地构建和待审文件，允许在隔离 GF 工作树中管理本地修改/检查点，但不得自动修改远程状态。
- 重型 Race、自举、内存压力测试不得与其他 worktree 的重型测试争抢同一台机器；无权杀死无关进程。
- 不靠关闭 GC、绕过类型检查、禁用指针布局检查、缩小固定测试语料、关闭 Race 或将失败改成预期成功来凑验收。
- 不将没有出现 DATA RACE 警告的超时任务算作 Race PASS；不把纯 Mio 原生程序中的 `Go not found in PATH` 算作没有嵌入 Go Runtime 的证明。

## 完成定义

- 仅当本包 `acceptance.md` 中 A1～A12、GF1～GF5 各阶段的硬门禁在**最终整合源码**实际通过，且证据可复现时，标注 `GO_FREE_SINGLE_BINARY=PASS`。
- 其余情况下明确 `NOT_ACCEPTED` / `BLOCKED`，但要完成所有仍能安全进行的工作；最后提供准确阻塞而非虚假进度。
- 不覆盖 GF0 报告中的事实，不自动变更 M19 的全仓 Race 历史验收状态。

如会话中断，下一次从 `status.json`、源码清单和日志恢复，先复核文件哈希/当前 HEAD，再继续剩余任务。
